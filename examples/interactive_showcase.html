    Security & limitations

    Built for careful AI reviews.

    This interactive preview uses fictional data. Download the Python package for real local reviews.

    What happens to my code?

    The server reads a limited, visible snapshot beneath the chosen local root. Clicking preview never calls a provider. Clicking Run council after explicit consent shares selected excerpts with the configured model. Secret scanning is best effort, not exhaustive.

    Where are my credentials?

    OpenAI, Gemini and Anthropic credentials must be environment variables in the terminal. The browser does not accept or expose API keys. Ollama uses a user-configured local service.

    What is verified?

    The local code unit tests and browser integration tests can verify application behavior. Model-generated decisions remain unverified until independently checked with evidence, tests and human review.

    Production limits

    Do not expose this server to the public Internet. It is bound to 127.0.0.1 only, uses a private session URL and allows one active review at a time. For team use, add authentication, managed secrets, rate limits and formal security review.

    ConsensusTree AI · Local-first open source · Preview ≠ verification · No external scripts, trackers or remote assets.
